## 1.0.13 (2026-05-12)

## 🐣 New Features
  None
## 🐞 Bug Fixes

- Fixed EthernetUtil.getEthernetIp() to correctly extract data from ShellCmd result
- Fixed WifiHotspotUtil methods to properly access ShellCmd execution data:
  - clearAllNet()
  - setTrunkMode()
  - setBridgeMode()
  - setStaModeForStaticIP()
  - setStaModeForToDynamicIP()
  - getNetworkConfigInfo()
- Fixed SystemProperties methods to handle ShellCmd return values:
  - getSystemProperty()
  - setSystemProperty()
  - getWifiMAC()

### Configuration
- Added mavenLocal() repository in settings.gradle.kts for both pluginManagement and dependencyResolutionManagement

## Technical Details
All ShellCmd.exec() calls now properly access the `.data` property to extract command output,
ensuring correct string parsing and comparison operations throughout the network and system utilities.

## 1.0.12 (2025-11-21)

## 🐣 New Features

- 【WiFi】Enhanced WiFi connection utility with support for multiple security protocols
  - Added WEP, WPA-PSK, WPA2-PSK security type support
  - Added automatic security type detection for reliable connections
  - Added hidden network support with extended timeout handling
- 【WiFi】Improved connection lifecycle management
  - Added context validity checks to prevent DeadObjectException
  - Implemented non-blocking connection timeout mechanism
  - Added proper return values for connection status tracking

## 🐞 Bug Fixes

- 【WiFi】Fixed issue where open network connection would return success even when network was unavailable
- 【WiFi】Resolved connection timeout problems with hidden WiFi networks
- 【WiFi】Improved error handling and logging for better debugging
- 【WiFi】Fixed thread blocking issues during long connection operations
